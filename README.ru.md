# Hermes Command Center

[English](README.md)

Расширение для собственного экземпляра Hermes WebUI. Открывается из интерфейса WebUI и показывает доступные сведения о Hermes и хосте через локальный сервис с доступом только на чтение. Если источник недоступен, панель сообщает об этом. Отдельный демонстрационный режим запускается со статическими файлами и явно обозначает тестовые данные.

## Установка

Используйте Python 3.10 или новее на Linux-хосте с глобальным экземпляром Hermes WebUI, которым управляет один доверенный оператор. Запустите архив от имени владельца каталога данных WebUI. Установщик находит стандартные расположения WebUI и проверяет параметры запуска экземпляра.

```sh
python3 ./hermes-command-center-0.2.2.pyz install --systemd
```

Например, для пользователя `hermes` команда автоматически найдёт `/home/hermes/hermes-webui` и использует данные из `/home/hermes/.hermes/webui`. Если найдено несколько установок или каталоги отличаются, укажите `--webui-root` и при необходимости `--state-dir`.

Если vLLM работает на другом узле частной сети, добавьте к команде `--vllm-origin http://10.20.30.40:8000`, заменив адрес и порт фактическими.

Чтобы получать показатели GPU с того же узла, добавьте `--gpu-ssh-user hermes` с фактическим именем SSH-пользователя. Для этого должны уже работать вход по ключу без интерактивных запросов и проверка ключа хоста. Команда `python3 ./hermes-command-center-0.2.2.pyz check` проверяет совместимость WebUI в режиме чтения.

Обновите страницу WebUI. В разделе **Настройки → Расширения** найдите **Hermes Command Center** и разрешите доступ через прокси WebUI к локальному сервису. Для разрешения `token-v1` в WebUI должна быть включена аутентификация. Откройте Command Center и проверьте, что панель получает живые данные.

Ручной запуск сервиса, переопределение каталога данных, проверка архива и команды управления описаны в [инструкции по установке](docs/INSTALL.md). Команда `python3 package.py` собирает архив из исходного кода.

## Обновление с v0.1.0

```sh
python3 ./hermes-command-center-0.2.2.pyz update
```

Обновление сохраняет параметры vLLM и GPU, состояние расширения и ранее выданное согласие на прокси. После перезапуска службы HCC обновите страницу WebUI. Проверки браузера и границы доступных данных описаны в [отчёте о приёмке v0.2.0](docs/ACCEPTANCE-v0.2.0.md).

## Демо

Из каталога с исходным кодом выполните `python3 -m http.server 8765 --bind 127.0.0.1 --directory web` и откройте [локальную демоверсию](http://127.0.0.1:8765/?demo=1).

## Данные и доступ

Сервис слушает `127.0.0.1:17882`. Панель обращается к нему через авторизованный прокси расширений WebUI. Сервис читает источники Hermes, Pi и vLLM. При закрытом браузере он продолжает записывать наблюдения в собственный закрытый каталог телеметрии. История использования строится по измеренному приросту счётчиков с момента установки.
